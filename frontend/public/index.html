Features

🖐
Hand Tracking
21-point MediaPipe landmark detection. Hold 1.5s to lock a sign.
😐
Emotion Detection
DeepFace analyzes 6 emotions in real-time: Happy, Sad, Angry, Neutral…
🤖
AI Interpretation
Gemini 2.5 Flash converts sign-language gloss to natural English sentences.
🔊
Voice Output
Browser Speech API reads each locked word and the final sentence aloud.
⚡
Real-time Pipeline
5 FPS inference loop with async state machine for smooth UX.
🚀
Fully Hosted
Frontend on Vercel. Backend on Render. Zero DevOps for viewers.

Deploy in minutes

Backend → Render
1. Push backend/ to GitHub
2. New Web Service on Render
3. Build: pip install -r requirements.txt
4. Start: uvicorn main:app …
5. Set GEMINI_API_KEY env var
6. Copy your .onrender.com URL
Frontend → Vercel
1. Push frontend/ to GitHub
2. Import project on Vercel
3. Root directory = frontend
4. Set VITE_API_URL = Render URL
5. Deploy → get .vercel.app URL
6. Add to your resume 🎉
